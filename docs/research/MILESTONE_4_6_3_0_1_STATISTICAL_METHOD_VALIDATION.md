## 1. Denominator Integrity & Metrics Separation

A critical finding of the Milestone 4.6.3.0.1 audit is that trade-level expectancy and candidate-level expectancy must never be conflated.

When evaluating news vetoes:
- Group A executes $N_A$ trades.
- Group B vetoes $V$ candidates and executes $N_B = N_A - V$ trades.

### The Three Formal Performance Denominators

1. **Expectancy Per Executed Trade ($E_{\text{trade}}$):**
   $$E_{\text{trade}} = \frac{\sum_{i=1}^{N_{\text{trades}}} \text{Net PnL}_i}{N_{\text{trades}}}$$
   *Interpretation:* Measures the average profitability of the positions actually taken. Answers: "When the strategy enters a trade, is it higher quality?"

2. **Expectancy Per Candidate Signal ($E_{\text{cand}}$):**
   $$E_{\text{cand}} = \frac{\sum_{i=1}^{N_{\text{trades}}} \text{Net PnL}_i}{N_{\text{candidates}}}$$
   *Interpretation:* Measures the total opportunity-set efficiency. For vetoed signals, $\text{Net PnL} = 0$. Answers: "Does news vetoing improve total net generation per candidate setup discovered?"

3. **Total Portfolio Return ($R_{\text{portfolio}}$):**
   $$R_{\text{portfolio}} = \frac{\sum_{i=1}^{N_{\text{trades}}} \text{Net PnL}_i}{\text{Initial Virtual Capital}}$$
   *Interpretation:* Measures aggregate compounding and net terminal wealth.

## 2. Moving Block Bootstrap Calibration

Financial returns exhibit autocorrelation, volatility clustering, and conditional heteroskedasticity. Standard i.i.d. bootstrap resamples destroy this dependence structure, leading to severely deflated standard errors and inflated false discovery rates.

Milestone 4.6.3.0 proposed a uniform block size of 48 bars.

### The Timeframe Inadequacy Identified by the Audit

- On 15m candles: 48 bars $\times$ 15 minutes = 12 hours. This is far too short; crypto regime persistence lasts several days.
- On 1d candles: 48 bars $\times$ 1 day = 48 days (~7 weeks). This is excessively long, causing extreme block overlap and high bootstrap variance.

### Calibrated Timeframe-Specific Block Sizes

To preserve realistic autocorrelation structures across all timeframes, NEPTUNE calibrates the block size to approximately **4 calendar days (96 hours)**:

| Timeframe | Calibrated Block Size (Bars) | Temporal Duration | Regime Captured |
|-----------|------------------------------|-------------------|-----------------|
| `15m` | 384 bars | 96 Hours (4 Days) | Microstructure autocorrelation, intraday volatility clusters |
| `1h` | 96 bars | 96 Hours (4 Days) | Intraday trend persistence, overnight momentum |
| `4h` | 24 bars | 96 Hours (4 Days) | Multi-day swing regime, funding rate cycle |
| `1d` | 7 bars | 7 Days (1 Week) | Weekly macro cycle, weekend drift |

## 3. Matched-Pairs Candidate Bootstrap

Because Group A and Group B evaluate the exact same candidate signals generated by the deterministic technical strategy, candidate outcomes are naturally paired:

$$\Delta_j = \text{Net PnL}_{B, j} - \text{Net PnL}_{A, j} \quad \text{for candidate } j \in \{1, \dots, N_{\text{candidates}}\}$$

Where:
- If neither vetoed: $\Delta_j = \text{Net PnL}_{B, j} - \text{Net PnL}_{A, j}$ (typically 0 unless execution gap differs).
- If Group B vetoed: $\text{Net PnL}_{B, j} = 0$, so $\Delta_j = - \text{Net PnL}_{A, j}$.
  - If Group A lost money: $\Delta_j > 0$ (favorable veto).
  - If Group A made money: $\Delta_j < 0$ (missed profit opportunity).

The null hypothesis of zero net expectancy difference ($H_0: \mathbb{E}[\Delta] \le 0$) is tested using 2,000 block-bootstrap resamples of the paired sequence $\{\Delta_j\}$.

## 4. Multiple Testing Correction

The confirmatory hypothesis family consists of three pre-registered tests:
- $H_1$: Group B vs. Group A (Technical Baseline).
- $H_2$: Group B vs. Group C (Frequency-Matched Control).
- $H_3$: Group B vs. Group D (Exposure-Matched Control).

To control the False Discovery Rate at $\alpha = 0.05$, the **Benjamini-Hochberg (FDR)** procedure is applied across the three $p$-values:

$$p_{(k)} \le \frac{k}{m} q^*$$

Where $m = 3$ and $q^* = 0.05$. Any other exploratory subgroup tests (e.g. by asset, by news category) are strictly designated as exploratory hypotheses.
